声ライブラリ

声の説明から候補を作り、試聴して登録すると会話で使えます。選んだ音声を参照として保存します。

保存済みの候補・参照ボイスは、一覧の「名前を変更」から名前を変更できます。

声作成はLargeをGPUで使い、ロード済みの言語モデルを自動で停止します。会話モードはCPUで動作します。高品質の長文合成はVoice Synthesizeで行えます。

候補は1つずつ生成します。複数指定時はseedを順に変えます。参照は30秒程度以上が推奨ですが、短い候補も試せます。
